## Signals
Signal: Dependent variable or function of one or more independent variables.

$$
\underbrace{ f }_{ \underset{\text{signal}}{\downarrow} }\overbrace{ (x_{1},x_{2},\dots ,x_{n}) }^{ \text{independent} }
$$
$ac \rightarrow s$
$dc \rightarrow \text{not } as$

i) Single variable signal

ex: $f(x),\quad g(t)$

ii)  Multi variable signal

ex: $f_{1}(x_{1},x_{2}), \quad g_{1}(t_{1},t_{2},t_{3})$
